プライバシーポリシー

アプリ名

友達と二人対戦リバーシ

1. 基本方針

本アプリの提供者（以下「当方」）は、本アプリにおける利用者の情報を、以下のとおり取り扱います。

本アプリは、氏名・メールアドレス・電話番号・住所・生年月日・位置情報・連絡先・写真など、ご本人を直接特定できる情報を取得しません。 アカウント登録やログインも必要ありません。

2. 取得する情報

情報内容
端末識別子本アプリが端末ごとにランダムに生成する識別子です。電話番号や端末固有の番号とは無関係で、本アプリを削除すると消滅します
対局の情報通信対戦の部屋番号・パスワード、先攻・後攻、打った手の記録、日時
広告識別子OS が提供する広告識別子（iOS：IDFA ／ Android：広告ID）。広告配信事業者が利用します

1台2人で遊ぶモードでは、対局の情報を送信しません。

3. 利用目的

  1. 通信対戦の提供（部屋の作成・参加、対局の進行、再戦）
  2. 不具合の調査
  3. 広告の配信

4. 端末内に保存する情報

本アプリが端末内に保存するのは、端末識別子と、通信対戦中の部屋・対局の識別子のみです。

5. 第三者への提供

当方が利用者の情報を第三者へ販売・提供することはありません。 ただし、以下のサービスを利用しているため、各社のプライバシーポリシーに従って情報が処理されます。

サービス提供者目的
Google AdMobGoogle LLC広告の配信
Unity AdsUnity Technologies広告の配信（Google AdMob を通じて）
Amazon Web ServicesAmazon.com, Inc.通信対戦のサーバーおよびデータの保管
Google フォームGoogle LLCご意見・不適切な広告の報告・不具合の報告の受付（送信された場合のみ）

Google のプライバシーポリシー：https://policies.google.com/privacy

Unity のプライバシーポリシー：https://unity.com/legal/privacy-policy

法令に基づき開示を求められた場合を除き、これ以外の第三者へ提供することはありません。

6. 保存期間と削除

情報保存期間
通信対戦の部屋・対局の情報（端末識別子を含みます）作成からおおむね1〜2日（経過後、自動的に削除されます）

削除の方法

  • 本アプリを端末から削除する … 端末内の情報（端末識別子など）がすべて消えます
  • 何もしない … サーバー上の情報は、上記の期間で自動的に削除されます

本アプリはご本人を特定できる情報を取得していないため、お問い合わせによる個別の削除では、該当するデータを特定できません。 上記のいずれかの方法をご利用ください。

同意の撤回

広告識別子の利用は、いつでも撤回できます。

  • iOS … 「設定」→「プライバシーとセキュリティ」→「トラッキング」から、本アプリの許可をオフにする
  • Android … 「設定」→「Google」→「広告」から広告IDを削除する

7. 広告について

本アプリでは、Google AdMob を通じて、Google および Unity Ads（Unity Technologies）の広告を表示します。広告配信事業者は、利用者の興味関心に応じた広告を表示するために、広告識別子を利用することがあります。

広告配信事業者は、広告の効果の測定や配信の改善のために、広告の表示・タップの有無や、購入の傾向などの情報を、各社のサービス全体で扱うことがあります。

  • iOS：初回起動時に「トラッキングの許可」を確認する画面が表示されます。許可しない場合でも、本アプリのすべての機能をご利用いただけます（表示される広告が興味関心に基づかないものになります）
  • Android：端末の設定から広告IDをリセットまたは削除できます

広告配信事業者は、広告の配信や不正の防止のために、IP アドレスからおおよその地域を推定することがあります。本アプリが位置情報（GPS など）を取得することはありません。

8. 未成年の方の利用

本アプリは年齢による利用制限を設けていませんが、児童を主たる対象としたアプリではありません。 未成年の方は、保護者の方の同意を得たうえでご利用ください。
